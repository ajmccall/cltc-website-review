# CLTC website design review

Five public design proposals, hosted separately from the club's live website.
Open index.html for all five options. This is a public review, not password-protected.
Pages carry noindex directives; robots.txt also discourages crawling.

This repository contains only allowlisted review HTML, CSS, screenshots, a combined
PDF, club branding and three gallery photographs. No member documents, source
newsletter tree, private project files or credentials are included. Newsletter
routes intentionally display a preview notice. Two existing Wix gallery images
remain externally hosted.

Generated by design-options/build-hosted-review.py in the local CLTC project.
GitHub Pages serves the root of the main branch. Do not upload the whole project.
